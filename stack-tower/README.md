# Stack Tower (Android)

Blocks slide left and right; tap to drop. Overhang is cut off so the tower narrows.
Land a block almost exactly on top for a **perfect** drop: it snaps, plays a chime that
rises in pitch with your combo, and 5+ combos slowly regrow the block.

Open this folder in Android Studio (Hedgehog+) and run, or `gradle assembleDebug`
(needs the Android SDK; use Android Studio to generate the Gradle wrapper).
Sounds are synthesised at runtime — no assets. Best score is saved locally.

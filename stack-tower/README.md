# Stack Tower (Android)

Tap to drop the sliding block. Overhang is sliced off, so the tower narrows. Line a block up
almost exactly for a **PERFECT** drop: it snaps, chimes (pitch climbs with your combo), and after
4 perfects in a row your block grows back.

## Features
- Pseudo-3D shaded blocks, squash on landing, falling cut-offs, screen shake, sparkles, haptics
- Smooth sine-eased sliding, drop animation, gentle tower sway as it gets tall
- Living world: day -> sunset -> night -> space as you climb (sun, moon, stars, clouds, birds,
  shooting stars, a ringed planet and a passing UFO)
- Curiosity hooks: dashed landmark lines (Giraffe, Eiffel Tower, Airplane, the Moon, Saturn...),
  rare slow golden blocks (+3 and extra width), "next landmark" counter
- Menu, pause button, sound toggle, first-run hint, game-over card with zoom-out view of your tower,
  saved best score
- All sound effects are synthesised at runtime (no asset files)

Open this folder in Android Studio (Hedgehog+) and run, or `gradle assembleDebug` with the Android SDK.
